Using a layout in StarCraft II

  1. Load the file. Add it to your mod's Base.SC2Data/UI/Layout/DescIndex.SC2Layout, or load it from triggers.
  2. Attach visual frames. Put new controls inside an existing path such as GameUI/.... Select a stock container in this editor before inserting, and the editor will create the required override.
  3. Wire behavior. A visible Button does nothing by itself. Use File → Export Triggers XML, or connect the frame in your existing Galaxy/trigger code.

The preview checks layout structure and placement. It cannot simulate campaign data, trigger arrays, or Galaxy code that expects a fixed number of frames.
